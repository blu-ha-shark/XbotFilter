# XbotFilter（貼文管理模式分支）

X/Twitter 自訂關鍵字與帳號過濾器。在瀏覽 X 時，自動將包含指定關鍵字的貼文或特定使用者名稱的貼文隱藏，避免機器人洗版並保持留言區乾淨。

這個分支在 `main`（純過濾版）的基礎上，額外加入了 **貼文管理模式**：針對自己貼文下方的機器人回覆，提供一鍵隱藏/封鎖的批次處理面板；針對別人的貼文，則提供批次封鎖可疑帳號的工具。

> ⚠️ **這個分支包含自動化點擊功能，使用前請務必閱讀本文件最下方的「使用風險與注意事項」。**

## 功能特點

### 三種互斥模式（過濾模式 / 選中模式 / 貼文管理）

設定面板把這三種模式改成同一列的三顆按鈕，**同時間只能啟用一個**（再按一次目前啟用中的按鈕會變成全部關閉）：

| 按鈕 | 行為 |
|---|---|
| **過濾模式** | 符合關鍵字的貼文直接隱藏（`display: none`） |
| **選中模式** | 符合關鍵字的貼文**不隱藏**，改在上方顯示藍色徽章（例如：`已被 貼文內容：[關鍵字] 選中`），用於除錯、確認過濾邏輯是否抓對 |
| **貼文管理** | 在「選中模式」的標記結果上，額外掛上 checkbox 與浮動操作面板，讓你批次處理這些留言 |

啟用中＝綠色，未啟用＝灰色。

### 文字複製模式（獨立開關）

跟上面三種模式無關，可以同時開關。開啟時解除 X 對貼文文字的選取限制、阻擋個人頁面 HoverCard、避免選取文字時誤觸連結跳轉。

### 貼文管理模式

這是本分支的核心功能。開啟後，只要目前分頁是「某則貼文的留言串頁面」，畫面右下角就會出現浮動面板，並自動判斷你的身分：

- **發文者身分**（你自己的貼文）：面板顯示
  - `一鍵隱藏選取`：對勾選的留言依序執行「隱藏回覆」
  - `一鍵隱藏+封鎖選取`：隱藏的同時，在跳出的確認對話框中一併點選封鎖
  - 完成後可選擇「保留頁面」或「跳轉至隱藏清單」（會用你帳號正確大小寫的 ID + 對話串最上層初始貼文的狀態 ID 組出正確網址，例如 `x.com/Blu_ha_Shark/status/1805.../hidden`）
- **讀者身分**（別人的貼文）：面板顯示
  - `匯出名單並封鎖選取`：先把目前勾選的帳號（顯示名稱＋@帳號）匯出成 `封鎖使用者名單.txt`，再依序打開每則留言的「更多(⋯)」選單、點封鎖、點確認封鎖

兩種身分下，符合關鍵字的留言（排除頁面最上層的主貼文）都會在「更多(⋯)」按鈕右側掛上一個 checkbox，代表這則留言目前是否要被納入批次處理。

#### 臨時名單機制

由於 X 的留言區是虛擬清單（捲動時 DOM 節點會被回收顯示不同貼文），貼文管理模式不用 DOM 節點本身當作狀態依據，而是維護一份以 **@帳號** 為 key 的臨時名單，每筆記錄包含：

- `@ID`：用來在畫面上重新找回這則留言
- checkbox 的 ON/OFF 狀態：使用者手動勾選/取消勾選的結果
- 捲動位置：偵測到當下的頁面捲動高度，之後批次處理時會先捲到這裡讓留言重新掛載

往下捲動出現新留言、或往上捲動回收節點顯示不同留言時，都會依 @ID 比對名單：如果名單裡已經有這個帳號，就把記錄的 ON/OFF 狀態套用到（重新掛載的）checkbox 上；沒有的話就新增一筆記錄。

換頁（切換到別的貼文串）時，臨時名單會被清空，0.5 秒後對新頁面重新掃描一次。

#### 批次處理流程與失敗重試

按下面板上的封鎖/隱藏按鈕後，會進入一個迴圈：

1. 檢查名單內有沒有「勾選中、且尚未標記完成」的項目，沒有就停止。
2. 有的話，捲動到該項目記錄的位置，等留言重新掛載出來。
3. 執行動作（隱藏回覆，或打開選單點封鎖）。
4. （封鎖流程）重新打開該留言的選單，確認選項是否已變成「取消封鎖」，藉此判斷封鎖是否成功；失敗的話會重置選單狀態後重試一次。
5. 標記該項目完成，從名單移除，隨機延遲 1.5～3 秒後回到第 1 步。

處理過程中，面板上的按鈕、全選/取消全選、以及每則留言的 checkbox 都會被鎖定禁用，滑鼠滾輪也會被暫時擋下，避免使用者手動操作跟自動化流程互相干擾。

#### 虛擬清單容錯

- 每則貼文用自己的狀態網址 ID 當「簽章」，MutationObserver 之外還會每 800ms 額外輪詢核對一次，確保 X 在原地更新內容（不一定會觸發標準 DOM 新增/移除事件）時，篩選結果也能正確跟著更新。
- 節點被回收顯示不同貼文時，會先清除舊的 badge/checkbox，避免殘留狀態串到新內容上。

### 其他既有功能（與 main 分支相同）

- ⚓ 滾動位置錨定：過濾/重新掃描時鎖定目前可見貼文的相對位置，避免畫面上下跳動。
- 🌗 黑暗模式切換。
- 📝 關鍵字分頁管理（新增／編輯／刪除／防重複）。
- 💾 設定匯入／匯出為 `.txt`（含新版三模式與舊版 `.json` 相容）。

## 安裝方式（Chrome / Edge）

1. 開啟瀏覽器的擴充功能管理頁
   - Chrome：`chrome://extensions/`
   - Edge：`edge://extensions/`
2. 開啟右上角的「開發人員模式」
3. 點選「載入未封裝項目」
4. 選擇本專案資料夾（含 `manifest.json` 的目錄）
5. 前往 [x.com](https://x.com)，點擊工具列上的 XbotFilter 圖示進行設定

## 使用方式

1. 點擊擴充功能圖示開啟設定面板，在「貼文內容過濾」／「使用者名稱過濾」分頁輸入關鍵字或帳號。
2. 依需求點選「過濾模式」「選中模式」「貼文管理」三顆按鈕其中之一（三選一，再點一次可全部關閉）；「文字複製模式」可獨立開關。
3. 若開啟「貼文管理」，前往任一則貼文的留言串頁面，右下角會出現浮動面板：
   - 勾選要處理的留言（預設全部勾選，可個別取消）。
   - 按下對應的動作按鈕（發文者：隱藏／隱藏+封鎖；讀者：匯出並封鎖）。
   - 處理期間請勿手動捲動或點擊面板按鈕，系統會自動鎖定直到跑完。

## 技術原理

- **動態監聽**：`MutationObserver` 監測 DOM 變化，並額外每 800ms 輪詢比對貼文簽章，兩者互補以因應虛擬清單的各種更新方式。
- **過濾機制**：掃描 `[data-testid="tweetText"]`、`[data-testid="User-Name"]` / `User-Names` 取得文字與帳號內容，比對關鍵字（不分大小寫）。
- **貼文管理**：以 `chrome.runtime.onMessage` 讓 popup 詢問目前分頁是否為可用的貼文留言頁面；身分（發文者／讀者）由目前登入帳號與網址中的使用者 ID 比對決定（比對時忽略大小寫，但組網址時保留原始大小寫）。
- **資料儲存**：`chrome.storage.sync` 儲存設定，可跨裝置同步。貼文管理的臨時名單只存在記憶體中，不會寫入 `chrome.storage`，換頁或關閉分頁即消失。

## 使用風險與注意事項

貼文管理模式的隱藏／封鎖批次處理，是透過模擬點擊瀏覽器畫面上的「更多」選單、選項、確認對話框來完成，**不是**透過 X 官方 API。這種「瀏覽器自動化」的做法，跟 X 目前的服務條款與開發者規範有明確衝突：

- X 開發者規範明文寫道：非透過官方 API 的自動化（包含瀏覽器自動化）會導致永久停權。
- X 服務條款也規定，除了官方公開介面之外，不得以任何方式（自動或非自動）存取服務。

**需要澄清的是：** 隱藏自己貼文的回覆、封鎖可疑帳號，這些*行為*本身完全合法、任何使用者都能手動做。真正的風險在於「用腳本自動幫你連續點擊」這件事本身，X 的偵測系統是看操作模式，沒辦法可靠分辨「防垃圾留言的個人工具」跟「惡意機器人」。

建議：

- 把這當成**個人、偶爾手動觸發、小批次**使用的輔助工具，而不是無人值守長時間運行的自動化程式。
- 不建議公開發佈（例如上架 Chrome 線上應用程式商店）或大量帳號共用，這會提高被系統標記的機率。
- 政策內容會隨時間變動，使用前可自行到 X 官方頁面確認最新規定：
  - <https://help.x.com/en/rules-and-policies/x-automation>
  - <https://docs.x.com/developer-guidelines>

以上不構成法律意見，僅為根據目前公開規則整理的風險提示，實際後果依 X 當下的執行狀況而定。
